# House Price Prediction using Linear Regression

## SkillCraft Technology Internship - Task 1

### Project Overview

This project predicts house prices using a Linear Regression model. The prediction is based on three features:

- Area
- Number of Bedrooms
- Number of Bathrooms

### Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

### Dataset

Housing Price Dataset

### Steps Performed

- Loaded the dataset
- Selected the required features
- Split the dataset into training and testing data
- Trained a Linear Regression model
- Evaluated the model
- Predicted house prices
- Created a graph of Actual Price vs Predicted Price

### Model Evaluation

The model performance is measured using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
